# Corresponding source

The npm package includes its exact build identity, snapshot hash and download
location in `dist/npm/SOURCE.md`. Each standalone archive includes that build's
identity directly in its `SOURCE.md`.

Local uncommitted builds are explicitly labeled as worktree snapshots. They do
not claim that an older public commit contains the current source.

See [licensing and rebuilding](docs/licensing.md) for the source boundary,
third-party notices and outstanding distribution review.
